# HolyBible

A web application focused on Bible reading and 
studying, designed to make Scripture more accessible.

## About the Project

HolyBible is a personal project developed to 
provide a simple and accessible experience for 
reading and exploring the Holy Bible.

The project is also an opportunity to improve 
software development skills and apply concepts 
such as clean code, software architecture, and 
modern web technologies.

## Technologies

- React
- TypeScript
- CSS
